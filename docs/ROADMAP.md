# Roadmap

## MVP included
- [x] Role-based coordinator/student pages
- [x] Inventory catalogue and locations
- [x] Quantity-tracked stock and individually tracked assets
- [x] Issue validation and automatic 15-day due dates
- [x] Renewal approval and rejection
- [x] Partial returns and condition recording
- [x] Overdue view and transaction history
- [x] Initial workflow tests

## Recommended next iterations
- [ ] CSRF protection and stronger password/session policy
- [ ] Change asset status and aggregate quantity-stock release through a dedicated inventory condition UI
- [ ] Student self-registration disabled by default; coordinator import via CSV
- [ ] CSV/PDF exports and printable issue acknowledgement
- [ ] Email reminders for due soon / overdue
- [ ] Coordinator audit dashboard and stock adjustment form
- [ ] Search, filters, pagination, and reporting by programme/lab
- [ ] Database migrations and PostgreSQL deployment
- [ ] Accessibility review and mobile usability testing
- [ ] Institution-approved SSO and production security review
